Zum Jahresende bin ich, eher zufällig, über Frithjof Bergmann und einige seiner letzten deutschsprachigen Auftritte gestolpert. Mir war sein Name bis dato kein Begriff.

1. [NWX17 - Prof. Dr. Frithjof Bergmann auf der XING New Work Experience 2017](https://youtu.be/29IoGFD86QM)
2. [NWX18 - Prof. Dr. Frithjof Bergmann - New Work, New Work Culture](https://youtu.be/Runf2hsnWRo)
3. [NWXnow - Live Talk - Weichenstellung für New Work - Stärken fördern für eine neue Realität](https://youtu.be/MJ81u46WLNg)
4. [NWXnow - Frithjof Bergmann - Weichenstellung für New Work - EP #7](https://youtu.be/ZcyvpxlhA6I)

Zusätzlich zu den Videos habe ich eine Liste von Podcast Folgen mit und über Frithjof zusammen gestellt.
