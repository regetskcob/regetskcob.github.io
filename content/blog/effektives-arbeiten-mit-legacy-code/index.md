Geschrieben von Michael C. Feathers und ins deutsche übersetzt bietet „Effektives Arbeiten mit Legacy Code“ einen Ratgeber für all die wenigen, die sich mit Bestandssystemen und ‚historisch gewachsenem‘ Code herum schlagen müssen.

## Das Buch

Auf rund 430 Seiten erläutert Feathers die Mechanik von Software-Änderungen. Er geht auf das Hinzufügen von Features, das beheben von Fehlern, aber auch Design- und Performance Verbesserungen ein. Auch das Kombinieren mehrere dieser Vorgehen wird aufgezeigt. Nach dem Entwickeln neuer Funktionen sollten diese beispielsweise auf Fehler getestet werden, aber auch der Code ‚drum herum‘ muss getestet werden, um die Integration der neuen Funktion im gesamten Kontext zu testen..

### Details

Im weiteren Verlauf des Buches erlernt ihr immer mehr, wie sich Software verändert, wenn wir etwas an ihr ändern. Mit jeder Änderung bauen wir neues Potential ein, wo es zu Fehlern kommen kann.

Um dies zu vermeiden zeigt euch Michael Feathers, wie ihr diesem Phänomen mit Hilfe von Unit Tests entgegen wirken könnt. Diese sollen automatisiert sicherstellen, dass bestehender Code weiterhin fehlerfrei funktioniert, genau so wie den neuen Code zu prüfen.

Darüber hinaus erfahrt ihr, wie man Stellen im Quellcode erkennen kann, an denen Änderungen durchgeführt werden sollten. Beispielsweise Zugriffe auf Objekte in einer Liste, ohne die Listengröße mit dem Index zuvor zu prüfen.

 Zu guter letzt erfahrt ihr Techniken und Hinweise, wie man Abhängigkeiten zwischen Code- und Programmteilen auflösen kann, um diese besser warten und testen zu können.
