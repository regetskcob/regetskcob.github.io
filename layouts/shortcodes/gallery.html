{{- /* A group of three or more images in a post as a photo grid, the same grid as the galleries (partials/photo-grid.html): breaks out of the text column, runs two to four columns, portraits take two rows. Used in a post as {{< gallery >}} ![Alt text](./one.jpg) ![Alt text](./two.jpg) ![Alt text](./three.jpg) {{< /gallery >}} The images are those of the post's own folder (no remote ones), in the order written. A click opens the lightbox with this gallery's photos to page through, titled like the post (assets/js/lightbox.js, partials/photo-grid.html). Two images that belong together stay with {{< images >}}. Without JavaScript each tile links to the large rendition. Large tiles come by one rule for all galleries (assets/js/series.js): one for every seven photos, alternating landscape and portrait, landscape first. The order stays as written; "shuffle=true" mixes it on every visit: {{< gallery shuffle=true >}} */ -}} {{- $page := .Page -}} {{- $items := slice -}} {{- range findRE `!\[[^\]]*\]\(\./[^)]+\)` .Inner -}} {{- $m := findRESubmatch `!\[([^\]]*)\]\(\./([^)]+)\)` . -}} {{- $alt := index (index $m 0) 1 -}} {{- $name := index (index $m 0) 2 -}} {{- with $page.Resources.Get $name -}} {{- $items = $items | append (dict "img" . "alt" $alt) -}} {{- else -}} {{- errorf "gallery shortcode in %s: no image %q in the post's folder" $page.File.Path $name -}} {{- end -}} {{- end -}} {{- $shuffle := eq (printf "%v" (.Get "shuffle")) "true" -}} {{- partial "photo-grid.html" (dict "items" $items "title" (replaceRE `^[^\p{L}\p{N}]+` "" $page.Title) "page" $page "shuffle" $shuffle) -}}
