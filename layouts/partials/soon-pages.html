{{- /* The posts announced as previews ("Vorschau"), as a list of pages. Takes the name of a series to keep only its parts, or "" for all of them. The names stand under "soon" in content/blog/_index.md, one per post folder. The posts themselves carry build: render: never list: never in their front matter: Hugo builds no page for them and leaves them out of every list (RSS, sitemap, tags, series parts, previous/next). They are only reachable by name, which is what this partial does, so a preview can never turn into a half-finished post by accident. Removing the name and the "build" block publishes the post. */ -}} {{- $series := . -}} {{- $pages := slice -}} {{- with site.GetPage "/blog" }} {{- range .Params.soon }} {{- with site.GetPage (printf "/blog/%s" .) }} {{- if or (not $series) (eq (urlize .Params.series) (urlize $series)) }} {{- $pages = $pages | append . }} {{- end }} {{- end }} {{- end }} {{- end -}} {{- return $pages -}}
