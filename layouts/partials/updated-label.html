{{/* Small label "kürzlich aktualisiert" for a post in a list (partials/ post-entry.html and the series overview). It shows for a post that is older than four weeks but was changed within the last four weeks, counted from the day the site is built: a post that is new anyway needs no label, and one that was changed long ago does not either. A page outside the blog (the gear and recipes pages) shows the label on the strength of its "lastmod" alone. "Changed" is the post's "lastmod" in front matter, set by hand when the text was revised; without it Hugo takes the date, so nothing shows. The git history is not used on purpose: a commit that only tidies the front matter would otherwise mark every post. The label is as current as the last build, the site is only rebuilt on a push. The same place carries the label "kürzlich neu erschienen" (see below) and the label "Entwurf" for a draft. Drafts are only built in the local preview (hugo server -D, see .claude/launch.json); the live build never has one, so the label cannot show up on the site. */}} {{- if .Draft }} Entwurf {{- end }} {{- /* "kürzlich neu erschienen": a post published within the last 14 days that is also among the five newest, so a burst of posts does not mark half of the list. Never together with "kürzlich aktualisiert": a post that new is not "updated" (see below). Drafts and pages outside the blog have none. */ -}} {{- if and (eq .Section "blog") (not .Draft) (not (.Date.Before (now.AddDate 0 0 -14))) }} {{- $self := . }} {{- range first 5 (where (site.GetPage "/blog").RegularPages "Draft" false).ByPublishDate.Reverse }} {{- if eq .RelPermalink $self.RelPermalink }} kürzlich neu erschienen {{- end }} {{- end }} {{- end }} {{- $limit := now.AddDate 0 0 -28 -}} {{- /* Only posts have an age that counts. A page like the gear page has no date of its own: Hugo takes its lastmod as the date, so there only the lastmod counts. */ -}} {{- $old := or (ne .Section "blog") (.Date.Before $limit) -}} {{- if and $old (not (.Lastmod.Before $limit)) }} kürzlich aktualisiert {{- end }}
