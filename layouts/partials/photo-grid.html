{{/* A photo grid, shared by the series page and the galleries on the home page. Breaks out of the text column to up to 80% of the viewport and runs two, three or four columns depending on its width. One row is a 3:2 landscape at single-column width. Tile shapes: landscape 1 column x 1 row (default) portrait 1 column x 2 rows detected from the image, so a portrait sits next to two stacked landscapes wide 2 columns x 1 row detected for panoramas, ratio 1.9 and up large 2 columns x 2 rows set with "size: large" on the item The grid packs densely, so smaller tiles fill the gaps a large one leaves. Takes a dict: items list of dicts: img (image resource), alt, size, href shuffle true to randomise the order on every visit (assets/js/series.js) narrow true to stay within the text column instead of breaking out uniform true to give every tile the same 3:2 cell, ignoring portrait, panorama and "size: large" (the series teaser counts on it) page the page the grid is on, for the image rights in the structured data feature true to let series.js promote a few random landscape tiles to 2x2 on every visit, unless the items mark large ones themselves A tile with "href" links there (e.g. the series page). Otherwise it links to a large rendition of its photo, which series.js opens in a lightbox; the page includes partials/photo-grid-script.html once, after its last grid. */}}
{{- range $it := .items }} {{- $img := $it.img }} {{- $ratio := div (float $img.Width) $img.Height }} {{- $shape := "" }} {{- if $.uniform }} {{- /* every tile one cell */}} {{- else if eq ($it.size | default "") "large" }} {{- $shape = "is-large" }} {{- else if lt $ratio 1.0 }} {{- $shape = "is-portrait" }} {{- else if ge $ratio 1.9 }} {{- $shape = "is-wide" }} {{- end }} {{/* Rendered tile widths: half the phone screen on two columns, about a third of 80vw on three, and at most 350px once the capped gallery runs four. Two-column tiles are twice that. */}} {{- $sizes := "(max-width: 640px) 50vw, (max-width: 1250px) 27vw, 350px" }} {{- if in (slice "is-large" "is-wide") $shape }} {{- $sizes = "(max-width: 640px) 100vw, (max-width: 1250px) 54vw, 700px" }} {{- end }} {{- end }}
