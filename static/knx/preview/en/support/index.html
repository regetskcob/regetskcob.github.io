    Support

    Something isn't working or you have an idea? Here you'll find answers to common questions and how to reach us.

    GitHub Issues

    Contact

    Please report bugs, questions and requests as an issue on GitHub: GitHub Issues

    Help us help you quickly

    • Device and version (e.g. iPhone, iOS 26, KNX Monitor 1.2 or the Home Assistant add-on)
    • Manufacturer and model of your KNX interface or IP router
    • What you did, what happened and what you expected
    • A screenshot if possible. Issues are public: please don't upload your ETS project or any passwords.

    Frequently asked questions

    Can I try the app without a KNX system?

    Yes. “Try the demo without a KNX system” on the start screen opens a sample house with a project and live values. Your own project stays untouched.

    What does KNX Monitor cost?

    The app is free and stays useful for everyday use. Plus costs €19.99 a year or €49 once, Pro €99 a year or €12.99 a month, with a free trial. The Home Assistant add-on and the Linux version are free for good; on Windows you buy through your account. Try everything in the demo house first, Pro included. Cancel a subscription any time in your App Store or Google Play account, on Windows via the link in Paddle’s email.

    Which KNX interfaces are supported?

    Any KNXnet/IP interface or IP router, for example a Gira X1. Tunnelling works over UDP or TCP; with an IP router you can also use routing, which needs no tunnel (not yet on iPhone and iPad, where multicast needs approval from Apple). USB and serial interfaces are not supported.

    Why can't I connect although the interface is reachable?

    IP interfaces only offer a few tunnels, often four or fewer. If visualisation, ETS or other apps use all of them, the interface refuses. Free a tunnel, configure an additional one in ETS, or use routing.

    Is KNX Secure supported?

    Yes: KNX IP Secure for the tunnel and KNX Data Secure for encrypted group addresses. Import the keyring (.knxkeys) from ETS. The keys are kept in your device’s keychain. If something doesn’t work with your interface, please report it on GitHub.

    Do I need an ETS project?

    No, the bus monitor works without one. With a project you get names, datapoint types, rooms and better checks. The password of a protected project is only used during import and is not stored.

    How do I get the desktop version?

    Windows and Linux do everything the iPad app does. Downloads are in the GitHub release; they are not signed yet, so SmartScreen may warn on Windows. On the Mac, KNX Monitor comes through the App Store.

    What do I need for the KNX box?

    A Raspberry Pi 4 or 5, ideally with a USB SSD and a real-time clock (Pi 5: battery, Pi 4: RTC module), plus the iPhone or iPad with the app. The box also sets its clock from the iPhone or the KNX time master. The ready-made image is in the GitHub releases, everything else on the KNX box page; it is a first preview.

    The app doesn't find my interface automatically.

    Discovery uses multicast on the local network. Guest Wi-Fi, VLANs or mesh systems sometimes block it. In that case, enter the interface’s IP address manually. On iPhone, local network access must also be allowed (Settings → KNX Monitor).

    Importing my ETS project fails.

    Check that the password is correct and the file is complete (.knxproj exported directly from ETS). Alternatively, export the group addresses as CSV from ETS and import that.
