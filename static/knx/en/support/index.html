Frequently asked questions

Can I try the app without a KNX system?

Yes. “Try the demo without a KNX system” on the start screen opens a made-up sample house with a project and live values. Your own project stays untouched and the demo stores nothing.

Which KNX interfaces are supported?

Any KNXnet/IP interface or IP router with tunnelling, for example a Gira X1 or an IP interface or router from another manufacturer. USB and serial interfaces are not supported.

Why can't I connect although the interface is reachable?

IP interfaces only offer a few tunnels, often four or fewer. If visualisation, ETS or other apps use all of them, the interface refuses further connections. Free a tunnel or configure an additional one in ETS.

Is my ETS project password stored?

No. The password is only used to decrypt the project during import and is discarded afterwards. Only the names, datapoint types and structure read from the project are stored, locally on your device.

Is KNX Secure supported?

Not yet. Secure tunnelling and encrypted group communication (KNX Data Secure) are currently not supported. Unencrypted telegrams on the same bus are shown as usual. If you need KNX Secure, vote with 👍 on GitHub – it helps us prioritise.

Is KNXnet/IP routing (multicast) supported?

Not yet. With a KNX IP router, routing would let you listen to the bus without occupying a tunnel. There is no IP router available for testing yet, so it isn’t planned. If you would use routing, vote with 👍 on GitHub – and get in touch if you can test with your router.

Do I need an ETS project?

No, the bus monitor works without one. With a project you get names, datapoint types, rooms and more meaningful checks.

The app doesn't find my interface automatically.

Discovery uses multicast on the local network. Guest Wi-Fi, VLANs or mesh systems sometimes block it. In that case, enter the interface’s IP address manually. On iPhone, local network access must also be allowed (Settings → KNX Monitor).

Importing my ETS project fails.

Check that the password is correct and the file is complete (.knxproj exported directly from ETS). Alternatively, export the group addresses as CSV from ETS and import that.
